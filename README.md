## Работа с нескольких устройств

На новом устройстве клонируй репозиторий один раз.

```sh
git clone https://github.com/LionKMufasa/NIRS_VKR.git
cd NIRS_VKR
```

Перед началом работы на любом устройстве выполни `git pull --ff-only` из папки проекта. Перед сменой устройства проверь правки командой `git status`, добавь нужные файлы через `git add`, сделай коммит и выполни `git push`. На другом устройстве снова выполни `git pull --ff-only`, чтобы получить этот коммит.
