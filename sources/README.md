# Первоисточники

Сюда добавляются оригиналы статей, книг, стандартов, заданий и методичек по мере появления. Местоположение файла фиксируется в [реестре](../knowledge/01_research/source_registry.md). Архив PDF из указателя НИРС в текущей папке проекта отсутствует. Перед добавлением материалов проверь право на их размещение в публичном репозитории.
