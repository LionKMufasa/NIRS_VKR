| --- | --- |

| ICS | Industrial Control System, промышленная система управления |
| IDS | Intrusion Detection System, система обнаружения вторжений |
| OT | Operational Technology, операционные технологии |
| SCADA | Supervisory Control and Data Acquisition, диспетчерское управление и сбор данных |
| SIEM | Security Information and Event Management, управление информацией и событиями безопасности |
