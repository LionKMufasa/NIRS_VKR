# Контекст проекта

Обновлено 18.11.2026. Статус — рабочий контекст.

Проект объединяет НИРС, НИР, разработку и подготовку ВКР. Цель текущего черновика — систематизировать методы обнаружения атак на АСУ ТП с помощью SIEM и сформулировать требования на основе обзора. В черновике сопоставляются средства мониторинга и наборы данных.

По рабочему замыслу из диалога «Промпт и структура базы знаний» итог проекта включает научное обоснование, документацию и программную реализацию. Название ВКР, состав реализации и критерии приёмки требуют уточнения.

См. [карточку обзора](../04_academic/literature_review.md), [план](roadmap.md) и [правила оформления](../05_documentation/formatting_rules.md).
