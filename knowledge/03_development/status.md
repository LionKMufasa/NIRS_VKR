# Состояние разработки

Обновлено 18.11.2026. Статус — подготовка материалов для проектирования.

По рабочему плану рассматривается собственная система или модуль на основе изучения открытых решений. В доступном дереве проекта исходного кода и утверждённой архитектуры пока нет. Указатель НИРС содержит документацию Wazuh, Security Onion, Suricata и Elastic. Присутствие инструмента в указателе означает, что его можно изучить в рамках обзора.

Перед выбором реализации зафиксируй требования по итогам [исследования](../01_research/research_questions.md), а затем критерии сравнения платформ и проверки прототипа. Согласованные решения внеси в [журнал](../00_project/decisions.md).
